# 文档反馈工单说明

文档站每个页面右下角都有 **💬 反馈** 入口，可提交“示例运行失败”或“内容疑问”。

## 提交时会保存什么

- **页面版与定位**：当前文档版本号、页面路径、锚点，以及锚点对应段落标题的文字快照。
- **环境声明**：浏览器语言、视口尺寸等用于复现的信息（仅维护者可见，不用于追踪）。
- **你的联系方式**：完全可选；留空即匿名，且默认不公开。
- **附件**：截图/日志默认**仅维护者可见**，不会对其他访客披露。

## 多版本与修复验证

同一问题可能横跨多个文档版本。维护者会为工单关联**多个受影响版本**，逐版本登记修复证据；
修复完成时必须注明**在哪个新版本验证有效**。在回执查询中，只有修复版本已经正式发布，
该版本才会标记为“已上线”，未发布的修复不会提前显示为已解决。

## 页面迁移与删段

- 页面迁移后，你的旧反馈仍保留提交时的原始定位；维护者人工确认后，才会建立到新位置的关系。
- 若反馈所指的段落被删除，工单不会被错误关闭，而是记录“文档删段”事件，可继续跟进。

## 离线与网络重试

- 离线或附件上传中断时，反馈会进入本机“待提交”队列，并携带**幂等键**。
- 联网后自动续传：已上传的分片不重传；重复的网络回执只会返回同一张工单，不会产生重复单。

## 回执查询

提交成功后请保存 **工单号 + 回执令牌**（仅展示一次）。凭回执可查看该工单各版本的处理状态与
完整事件流，包括直接状态修改、修复证据、复开与合并来源——处理来源不会因合并而丢失。

## 公开修订摘要

“修订摘要”页只展示**已核实事实**：修复版本已发布、且在该版本验证有效。草稿与未发布修复
不会公开。
